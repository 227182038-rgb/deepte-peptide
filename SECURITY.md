# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in DeepTE-Peptide (including potential credential exposure, unsafe deserialization, or dependency vulnerabilities):

1. Please **do not** open a public GitHub issue.
2. Report the vulnerability privately via GitHub Security Advisories on this repository or contact the project maintainers.
3. Include details of the vulnerability, reproduction steps, and any potential remediation.
4. The team will acknowledge receipt within 48 hours and coordinate a fix and release.
